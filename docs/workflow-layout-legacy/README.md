# 工作流布局整理器：迁移资料

本目录保存从原 `comfyui_workflow` 项目迁入的资料：

- `scripts/`：早期针对特定工作流的 PowerShell 排布脚本；用于追溯规则和示例，不由插件运行。
- `examples/`：已整理的工作流 JSON 示例。

插件中的实际功能位于 `web/js/features/workflow_layout/`。在 ComfyUI 画布空白处右键，选择“🧭 整理工作流布局”即可执行。

整理器只改变节点位置与分组：它不会变更节点参数、组件值、连线或工作流执行配置。布局规则为从左到右排列功能模块，模型区保持“大模型在上、CLIP 居中、VAE 在下”。
